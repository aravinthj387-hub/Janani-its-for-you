JANANI - FOR YOU ❤️

Files:
- index.html       Main webpage
- style.css        Design and animations
- script.js        Music player and heart animation
- For you.mp3     Your uploaded song

HOW TO USE:
1. Keep all four files in the same folder.
2. Open index.html in a browser to test it.
3. For a shareable public link, upload the whole folder to a static hosting service such as GitHub Pages, Netlify, or Vercel.
4. Make sure the MP3 stays in the same folder as index.html.

The page is mobile-friendly and includes:
- Play / pause
- Progress bar
- Song duration
- Animated record while playing
- Heart animation
- "Tap if you smiled" interaction
